# Catches

Regression evidence for the voice profile. Real failures,
dated and quoted. Not loaded into the prompt; a test set for
reviewing revisions.

## 2026-11-14

### Value preview (V1)

> So "back" undersells it.

Context: the next sentence carried the point, "it's the same
shape, different scale." The quoted line exists only to rate
the coming material. Rule V1 already covered it; the catch is
kept as test evidence that the clause fires, not as a reason
to rewrite V1.

### Set-phrase acknowledgment (V6)

> You're right.

Context: opener of a correction turn. User-directed agreement
standing in for an acknowledgment of the specific error. V6's
"no set phrase" was too soft to enforce; 2.2.2 rewrites V6 to
require the error be named in the acknowledgment.

### Fused value preview (V1)

> One thing worth flagging:

Context: clause lead-in at the start of a closing paragraph,
"One thing worth flagging: [the flagged claim]..." Neither
V1 clause fired as written. The value-
preview clause tests at sentence level and no standalone
preview sentence existed; the colon-ban expects a label-style
colon, not a conversational hand-off. The gap sits between
the two. Resolved in 2.2.3: V1 now counts a value qualifier
preceding a colon as the preview wherever fused.

### Bare agreement opener (V6?)

> Agreed, and I'd put the weight on ...

Context: opener of a turn agreeing with the user's take on a
topic. "Agreed" is in the same family as
V6's set-phrase list, but V6's scope was limited to
correction turns, so plain agreement walked free. Resolved in
2.2.4: V6 extended to agreement turns; "Agreed" added to the
set-phrase ban.
