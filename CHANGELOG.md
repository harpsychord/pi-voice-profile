# Changelog

## [2.3.2] - 2026-11-15

- Rule V1.2 extended against its trigger, dated in
  references/catches.md as "Standalone value preview". A value
  qualifier in the preview phrase itself, "worth a glance",
  walked past V1.2 under 2.3.1 even though the clause names
  the form in review; the form is a standalone fragment with
  no colon and no landing frame. V1.2 now counts a value
  qualifier in the preview phrase as a rating wherever it
  sits, alone, before a colon, or fused.

## [2.3.1] - 2026-11-14

- Rule V1.2 extended against its trigger, dated in
  references/catches.md as "Standalone value preview". A
  preview that reads as a hedge, "matters more than it
  sounds", walked past V1.2 under 2.3.0 even though the
  clause names the form in review. V1.2 now counts a rating
  framed as how the material will land as a rating.
- README rule count corrected from eight to nine. V9 was
  added in 2.2.0 and the intro line never followed.

## [2.3.0] - 2026-11-14

- Rule V1 broken up into a short parent plus clauses V1.1
  (start from the concrete), V1.2 (no preview), V1.3 (no
  grading), and V1.4 (no mechanical scaffolding). All V1
  content is preserved and moved, nothing dropped. V2-V9
  unchanged. Catch citations updated to clause level.

## [2.2.4] - 2026-11-14

- Rule V6 extended from correction turns to agreement turns,
  dated in references/catches.md as "Bare agreement opener".
  Set-phrase agreement ("Agreed," "You're right," "good
  catch," "fair," "exactly") is barred as an opener wherever
  it stands in for naming the specific point.

## [2.2.3] - 2026-11-14

- Rule V1 extended against its trigger, dated in
  references/catches.md as "Fused value preview". The
  value-preview clause is written at sentence level and
  missed a rating fused to its point with a colon in the
  same sentence. V1 now covers a value qualifier preceding
  a colon wherever it is fused with the content.

## [2.2.2] - 2026-11-14

- Rule V6 rewritten after two observed failures, dated in
  references/catches.md. The acknowledgment must name the
  specific error in one short clause; user-directed agreement
  ("you're right," "good catch," "fair," "exactly") is barred
  as an opener. Rule V1 is unchanged; its value-preview clause
  already covered the other failure, so that one is kept as
  test evidence only.

## [2.2.1] - 2026-11-14

- Rule V9 rewritten against its trigger. Parting lines fire
  on completion turns, so V9 now bans the second sentence on
  completion turns instead of only naming the motto class.

## [2.2.0] - 2026-11-14

- Document 2.2.0: new rule V9, no parting lines. Send-off
  blessings and closing mottos are scenes, not conversations.

## [2.1.1] - 2026-11-14

- Install docs now lead with the git source. The npm line is
  withdrawn until npm publishing is implemented, tracked by the
  repo issue tagged "not implemented".

## [2.1.0] - 2026-11-14

- Package layout for pi package distribution: extension code and
  references moved under extensions/, document resolved relative
  to the extension file so the package works from any install
  location.
- Document 2.1.0: regression evidence section generalized for
  published copies without a catches file.
- GPL-3.0, see LICENSE.

## [2.0.0] - 2026-11-14

- Document made self-standing: precedence clause generalized so
